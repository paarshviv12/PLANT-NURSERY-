Green Haven Nursery is a responsive, beautifully designed front-end landing page for a premium plant and bonsai e-commerce store. 

## 🌟 Features
- **Responsive Layout:** fully optimized grid structure for seamless viewing on all devices (mobile, tablet, desktop).
- **Interactive UI:** Dynamic hover effects, scale animations on plant images, and clean transitions for enhanced user experience.
- **Glassmorphism Nav:** A modern, sticky navigation bar with a blur effect.
- **Category Tags:** Easily identifiable tags positioned elegantly over product images for filtering between 'Indoor', 'Outdoor', and 'Bonsai' categories. 
- **Sticky Footer:** The layout utilizes flexbox strategies to guarantee the footer remains securely at the bottom of the page, regardless of content height.

## 🛠️ Built With
- **HTML5:** Semantic markup structure
- **CSS3:** Custom styling utilizing CSS Variables, Flexbox, and CSS Grid
- **FontAwesome:** Scalable vector icons (used for the leaf logo, cart, and add buttons)
- **Google Fonts:** Utilizing 'Outfit' and 'Playfair Display' for modern, elegant typography

## 🚀 Getting Started

To view this project locally, simply clone the repository and open the HTML file in your preferred browser.

### Installation

1. Clone the repo
   ```sh
   git clone https://github.com/paarshviv12/PLANT-NURSERY-.git
   ```
2. Open the directory
   ```sh
   cd PLANT-NURSERY-
   ```
3. Open `plants.html` in your web browser.
